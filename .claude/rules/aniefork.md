This repository is arcanii/pdfcraft, a fork of storytold/pdfcraft (the `upstream` remote). `CLAUDE.md` and `AGENTS.md` are upstream's files and stay unchanged here; this file says where the fork differs.

- **Log fork work in `ROADMAP-aniefork.md`, not `ROADMAP.md`.** `ROADMAP.md` stays identical to upstream so that merging upstream doesn't conflict. Where `CLAUDE.md` says to update `ROADMAP.md` at the end of a session, add a line to the log in `ROADMAP-aniefork.md` instead, and keep its "What the fork carries" table true.
- **A branch meant as an upstream pull request** follows upstream's rules, `ROADMAP.md` log line included. Cut it from `upstream/main`, not from the fork's `main`.
- **Syncing with upstream:** `ROADMAP-aniefork.md` lists the steps and the files that still conflict.
